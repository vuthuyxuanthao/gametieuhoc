📋 Danh sách trò chơi

#Trò chơiLớpMônThao tác

💾 Nội dung file games.js

Nếu file không tự tải về, bấm Sao chép, mở file games.js trên GitHub, xóa hết và dán vào.

🚀 Đưa thay đổi lên site

  1. Bấm 💾 Xuất games.js để tải file danh sách mới.
  2. Mở kho GitHub của site → thư mục kho-game → Add file → Upload files.
  3. Kéo vào: file games.js (thay file cũ) và thư mục games chứa các game mới, mỗi game là games/tên-game/index.html.
  4. Bấm Commit changes. Netlify tự cập nhật sau khoảng 1 phút, học sinh tải lại trang là thấy.

Thay đổi chưa xuất được lưu tạm trong trình duyệt máy này, tắt máy vẫn còn.
